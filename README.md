As licoes estao em `network-programming/licoes/`. O andamento detalhado fica em [PROGRESSO.md](network-programming/PROGRESSO.md).

## Ambiente

A trilha inicial usa C em Linux/POSIX para acompanhar o Beej. A instancia EC2 informada ainda nao foi validada quanto a estado, distribuicao Linux, compilador ou acesso remoto. A Licao 01 comeca por esses requisitos; nao pressuponha acesso a CloudShell, SSH ou Session Manager antes de testa-los.
